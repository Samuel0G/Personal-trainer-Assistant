# 🏋️ Personal Trainer (Python)

Sistema simples em Python que simula um **personal trainer básico**, realizando cálculos físicos e sugerindo dieta e treino com base nos dados do usuário.

---

## 📌 Funcionalidades

✔ Cálculo de IMC
✔ Cálculo de TMB (Taxa Metabólica Basal)
✔ Cálculo de gasto calórico diário
✔ Geração de plano nutricional (calorias e macronutrientes)
✔ Sugestão de treino baseada no objetivo

---

## 🧠 Tecnologias utilizadas

* Python 3
* Lógica de programação
* Estrutura modular (separação por arquivos)

---

## 📂 Estrutura do projeto

```
personal-trainer/
│
├── app.py            # Arquivo principal
├── calculos.py       # Cálculos (IMC, TMB, etc)
├── dieta.py          # Plano alimentar
├── treino.py         # Sugestão de treino
├── requirements.txt
└── README.md
```

---

## ▶️ Como executar

1. Acesse a pasta:

cd personal-trainer

2. Execute o programa:

python app.py

## 💻 Exemplo de uso

```
Idade: 25
Peso: 70
Altura: 175
Sexo: m
Nível: moderado
Objetivo: hipertrofia
```

Saída:

```
IMC: 22.86
TMB: 1700
Gasto Calórico Total: 2600

Calorias: 2800 kcal
Proteína: 140g
Gordura: 70g
Carboidrato: 350g
```
